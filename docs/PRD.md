## 1. Why - 목적

* 사용자가 일일/주간/1년 단위 목표를 계층적으로 관리할 수 있도록 한다.
* 할 일을 `todo → doing → done` 상태로 관리한다.
* 드래그 앤 드롭으로 빠르게 상태를 변경할 수 있도록 한다.
* 일일 할 일 완료 결과를 기반으로 주간 진행률을 자동 계산한다.
* 단기 실행 항목과 장기 목표를 하나의 구조에서 연결한다.

## 2. Who - 타깃 사용자

* 개인 일정과 업무를 함께 관리하는 사용자
* 하루 단위 할 일을 계획하고 실행하는 사용자
* 주간 목표 달성률을 확인하고 싶은 사용자
* 연간 목표를 주간/일일 실행 항목으로 관리하고 싶은 사용자
* 복잡한 프로젝트 관리 도구보다 단순한 할 일 관리가 필요한 사용자

## 3. User Flow

* 앱 진입

  * 현재 일일 할 일 목록 확인
  * 현재 주간 목표 및 진행률 확인
* 할 일 생성

  * 할 일 제목 입력
  * 기간 선택

    * 일일
    * 주간
    * 1년
  * 초기 상태 `todo` 설정
  * 저장
* 할 일 실행

  * `todo` 목록 확인
  * 할 일을 `doing` 영역으로 드래그
  * 상태 자동 변경
* 할 일 완료

  * 할 일을 `done` 영역으로 드래그
  * 상태 자동 변경
  * 주간 진행률 자동 재계산
* 할 일 수정

  * 할 일 선택
  * 내용 수정
  * 저장
* 할 일 삭제

  * 할 일 선택
  * 삭제
  * 주간 진행률 자동 재계산
* 기간별 확인

  * 일일 목표 확인
  * 주간 목표 및 진행률 확인
  * 1년 목표 확인

## 4. 기능 요구 사항

### P0 - 핵심 기능

* 할 일 CRUD

  * 생성

    * 제목 입력
    * 기간 유형 지정

      * `daily`
      * `weekly`
      * `yearly`
    * 생성 시 기본 상태 `todo`
  * 조회

    * 기간별 할 일 목록 조회
    * 상태별 할 일 목록 조회
  * 수정

    * 제목 수정
    * 기간 유형 수정
    * 상태 수정
  * 삭제

    * 개별 할 일 삭제
    * 삭제 후 목록 즉시 반영

* 상태 관리

  * 상태 값

    * `todo`
    * `doing`
    * `done`
  * 모든 할 일은 하나의 상태를 반드시 보유
  * 상태 변경 시 즉시 저장
  * 상태별 목록 제공

* 드래그 앤 드롭 상태 변경

  * `todo`, `doing`, `done` 영역 제공
  * 할 일을 다른 상태 영역으로 드래그 가능
  * 드롭 완료 시 상태 자동 변경
  * 변경 결과 즉시 UI 반영
  * 저장 실패 시 이전 상태로 복구

* 기간 구조

  * 기간 유형

    * 일일 목표
    * 주간 목표
    * 1년 목표
  * 일일 목표

    * 특정 날짜 기준 관리
  * 주간 목표

    * 특정 주 기준 관리
  * 1년 목표

    * 특정 연도 기준 관리
  * 기간별 목록 구분 제공

* 주간 진행률 자동 반영

  * 주간 진행률 계산 기준

    * 해당 주에 포함된 할 일 전체 수
    * `done` 상태 할 일 수
  * 계산식

    * `주간 진행률 = done 할 일 수 / 전체 할 일 수 × 100`
  * 상태 변경 시 자동 재계산
  * 할 일 생성 시 자동 재계산
  * 할 일 삭제 시 자동 재계산
  * 주간 화면에 진행률 표시
  * 전체 할 일이 0개인 경우 진행률 `0%`

* 기본 데이터 구조

  * Todo

    * `id`
    * `title`
    * `status`
    * `periodType`
    * `targetDate`
    * `createdAt`
    * `updatedAt`
  * status

    * `todo`
    * `doing`
    * `done`
  * periodType

    * `daily`
    * `weekly`
    * `yearly`

### P1 - 추가 기능

* 기간 간 목표 연결

  * 1년 목표와 주간 목표 연결
  * 주간 목표와 일일 할 일 연결

* 진행률 확장

  * 1년 목표 진행률 표시
  * 연결된 주간 목표 완료 기준으로 자동 계산

* 할 일 정렬

  * 상태 영역 내부 드래그 앤 드롭 순서 변경
  * 사용자 지정 순서 저장

* 완료 이력

  * 완료된 할 일의 완료 시각 저장
  * 기간별 완료 기록 조회

* 필터

  * 상태별 필터
  * 기간별 필터
  * 날짜별 필터

* 기본 유효성 검증

  * 제목 없는 할 일 생성 방지
  * 잘못된 기간 값 저장 방지
  * 존재하지 않는 상태 값 저장 방지
